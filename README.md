# ClassCheck

ClassCheck es un proyecto orientado a apoyar la gestión académica de una institución educativa.

## ¿Para qué sirve?

Su propósito es reunir en un solo sistema herramientas relacionadas con las clases, la asistencia y el seguimiento académico de los estudiantes, facilitando el trabajo de docentes y personal administrativo.

## Importancia

Llevar la información académica de forma ordenada ayuda a reducir tareas manuales, consultar los datos con mayor facilidad y dar un mejor seguimiento al avance de los estudiantes. ClassCheck busca contribuir a una gestión más clara y organizada para la comunidad educativa.
